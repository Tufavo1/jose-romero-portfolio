## El Problema

Necesidad de una solución simple para que clientes puedan agendar servicios de mantención
de hardware y consultas técnicas, con un panel de administración para gestionar las solicitudes.

## Solución

Landing page con sistema de agendamiento integrado y panel de administración para
gestionar el flujo completo de solicitudes.

## Stack Técnico

- **Frontend:** React + Tailwind CSS
- **Backend:** Supabase (auth + base de datos + realtime)
- **Deploy:** GitHub + Vercel

## Estado Actual

En construcción activa. Interfaz de administración implementada,
integrando flujo completo de agendamiento.
