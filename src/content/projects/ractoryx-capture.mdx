## El Problema

Clínica Dávila necesitaba una solución para capturar y analizar datos operacionales en tiempo real,
reemplazando procesos manuales que generaban retrasos y errores en la toma de decisiones.

## Solución

Desarrollé Ractoryx Capture, una plataforma SaaS que centraliza la captura de datos y entrega
dashboards en tiempo real para el equipo clínico.

## Stack Técnico

- **Frontend:** React + Tailwind CSS, desplegado en Vercel
- **Backend:** .NET Core 8 API con Azure
- **Base de datos:** Azure SQL
- **CI/CD:** GitHub Actions integrado con Azure para deploys automáticos

## Arquitectura

Pipeline completo desde captura de datos hasta visualización, con autenticación empresarial,
roles de acceso diferenciados y sincronización en tiempo real vía Azure.

## Resultado

Plataforma funcional y entregada. El proyecto fue concluido exitosamente; la decisión de no
continuar fue exclusivamente por razones presupuestarias del cliente.
